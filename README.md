## a. Problem Statement

A Portuguese bank runs direct-marketing campaigns (phone calls) to sell **term
deposits**. Calling every client is expensive and annoys uninterested
customers. The goal is to build classification models that predict — from a
client's demographic, financial and campaign-contact attributes — **whether
the client will subscribe to a term deposit (`y` = yes/no)**, so the bank can
focus its calls on the clients most likely to convert.

Five classification models (Logistic Regression, Decision Tree, kNN, Naive
Bayes, Random Forest) are trained **on the same dataset**, evaluated with six
metrics (Accuracy, AUC, Precision, Recall, F1, MCC), and demonstrated through
an interactive Streamlit web application deployed on Streamlit Community
Cloud.

## b. Dataset Description

- **Name:** Bank Marketing dataset
- **Source:** [UCI Machine Learning Repository — Dataset #222](https://archive.ics.uci.edu/dataset/222/bank+marketing)
- **Instances:** 4,521 clients *(minimum required: 500 ✅)*
- **Features:** 16 input features *(minimum required: 12 ✅)* — 7 numeric + 9 categorical
- **Target:** `y` — has the client subscribed to a term deposit? (yes/no)
- **Problem type:** Binary classification, **imbalanced** (≈ 88.5% "no", 11.5% "yes")

| # | Feature | Type | Description |
|---|---------|------|-------------|
| 1 | age | numeric | Age of the client |
| 2 | job | categorical | Type of job (admin., technician, blue-collar, …) |
| 3 | marital | categorical | Marital status |
| 4 | education | categorical | Education level |
| 5 | default | categorical | Has credit in default? |
| 6 | balance | numeric | Average yearly balance (euros) |
| 7 | housing | categorical | Has housing loan? |
| 8 | loan | categorical | Has personal loan? |
| 9 | contact | categorical | Contact communication type |
| 10 | day | numeric | Last contact day of the month |
| 11 | month | categorical | Last contact month of the year |
| 12 | duration | numeric | Last contact duration (seconds) |
| 13 | campaign | numeric | Number of contacts in this campaign |
| 14 | pdays | numeric | Days since last contact in previous campaign (-1 = never) |
| 15 | previous | numeric | Number of contacts before this campaign |
| 16 | poutcome | categorical | Outcome of the previous campaign |

**Train/test split:** 80/20 stratified split (3,616 train / 905 test rows,
`random_state=42`). The raw hold-out test split is provided as
[`test_data.csv`](test_data.csv) — upload this file in the Streamlit app.

**Preprocessing:** every saved model is a scikit-learn `Pipeline` bundling a
`ColumnTransformer` (one-hot encoding for categorical features + standard
scaling for numeric features) with the classifier, so raw CSV rows are scored
directly. `class_weight="balanced"` is used where supported because the
classes are imbalanced.

## d. Models Used — Comparison Table

All models trained on the same 3,616-row training split and evaluated on the
same 905-row hold-out test split (positive class = "yes").

| ML Model Name | Accuracy | AUC | Precision | Recall | F1 | MCC |
|---|---|---|---|---|---|---|
| Logistic Regression | 0.8232 | 0.8908 | 0.3716 | 0.7788 | 0.5031 | 0.4533 |
| Decision Tree | 0.7492 | 0.8194 | 0.2887 | 0.8077 | 0.4253 | 0.3750 |

### Observations on model performance

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Strong, well-rounded baseline: 2nd best AUC (0.8908) and MCC (0.4533). With `class_weight="balanced"` it catches ~78% of subscribers (high recall) at the cost of precision (0.37), i.e. more false alarms. Works well because many one-hot encoded features have a roughly linear effect on the log-odds of subscribing. |
| Decision Tree | Highest recall (0.8077) but the lowest accuracy (0.7492) and weak precision (0.2887) — a single balanced tree over-predicts the minority "yes" class and its axis-aligned splits generalize worse than the ensemble. Interpretable, but clearly outperformed by Random Forest, which averages many such trees. |
| kNN | Misleadingly high accuracy (0.8873 — best of all) but the worst recall (0.1250), F1 (0.2031) and MCC (0.2209): it mostly predicts the majority "no" class. A textbook example of the accuracy paradox on imbalanced data, and of distance-based methods struggling in the high-dimensional one-hot encoded space (curse of dimensionality). |
| Naive Bayes | Fast and decent middle-ground (Accuracy 0.8210, Recall 0.4519), but the lowest AUC (0.7881). Its conditional-independence assumption is violated (e.g. job/education/balance are correlated) and Gaussian likelihoods fit skewed features such as `balance` and `duration` poorly, capping its ranking quality. |
| Random Forest (Ensemble) | **Best overall**: highest AUC (0.9049), F1 (0.5541), MCC (0.5160) and recall among high-accuracy models (0.8365). Bagging + feature randomness reduce the variance of individual trees and capture non-linear feature interactions (e.g. duration × month × poutcome) that linear models miss. |
| **Overall Winner for your dataset?** | **Random Forest (Ensemble).** It dominates the threshold-independent AUC and the imbalance-robust metrics (F1, MCC) — the metrics that matter here, since plain accuracy is inflated by the 88.5% majority class. It finds ~84% of actual subscribers while keeping the best balance with false positives, which directly serves the business goal of targeting likely subscribers. |

## How to Run Locally

```bash
git clone https://github.com/<your-username>/ml-assignment-2-bank-classifier.git
cd ml-assignment-2-bank-classifier
pip install -r requirements.txt

# (optional) retrain the models — pickles are already included
python model/train_models.py

# launch the app
streamlit run app.py
```

Then open http://localhost:8501, pick a model from the sidebar dropdown, and
upload **`test_data.csv`**.

## Streamlit App Features (assignment requirements)

- ✅ **a. Dataset upload option (CSV)** — sidebar file uploader for the test data
- ✅ **b. Model selection dropdown** — choose any of the 5 trained models
- ✅ **c. Display of evaluation metrics** — Accuracy, AUC, Precision, Recall, F1, MCC on the uploaded test data
- ✅ **d. Confusion matrix / classification report** — heatmap + per-class report, plus ROC curve and a model-comparison tab

## Deployment (Streamlit Community Cloud)

1. Push this repository to GitHub (public).
2. Go to https://streamlit.io/cloud and sign in with GitHub.
3. Click **New App** → select this repository → branch `main` → file `app.py`.
4. Click **Deploy** — dependencies are installed automatically from `requirements.txt`.
